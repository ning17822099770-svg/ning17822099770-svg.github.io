# Ning Wang — Personal Website

Static academic and engineering portfolio, prepared for GitHub Pages.

## Publish

1. Use a personal site repository named `ning17822099770-svg.github.io`, with the username in lowercase. Inspect any existing repository before changing its contents.
2. Place `index.html` and `.nojekyll` in the root of the publishing branch.
3. In **Settings → Pages**, choose **Deploy from a branch**, the publishing branch (usually `main`), and **/(root)**; save.
4. Wait for the Pages deployment to succeed. The personal website address is `https://ning17822099770-svg.github.io`.

For a free GitHub account, the repository must be public.

## Included content

- Portfolio layout, photographs, project summaries, teaching experience, publications, and contact details.
- Embedded research resume PDF (2 pages) and engineering resume PDF (1 page).
- Images and PDFs are embedded in the HTML. No asset upload or package installation is required.
- Fonts are loaded from Google Fonts, with CSS fallback fonts.

After publishing, update LinkedIn Contact Info and Featured links to the verified GitHub Pages URL.
